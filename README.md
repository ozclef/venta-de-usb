## Antes de instalarle nada, OJO con estas tres cosas

- Windows de 64 bits a 32 bits: no es una migración directa conservando la instalación; normalmente requiere instalación limpia. Además, un procesador compatible con 64 bits puede ejecutar Windows de 32 bits, pero no al revés.
- Los programas pesados: los portables no hacen magia. Algunos requieren servicios, controladores, dependencias o más RAM; y los programas de 64 bits no funcionan en Windows de 32 bits.
- El disco duro original: no lo borres ni cambies el orden de arranque a ciegas. Primero confirma que no necesita archivos, guarda lo importante y comprueba que puedes regresar al sistema anterior.

Y si vas a instalar Windows, utiliza una licencia válida y una imagen de procedencia confiable. Las herramientas de rescate y las claves de activación son cosas distintas.
